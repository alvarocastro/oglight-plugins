# OGLight - Copy Coordinates

Shift+click any planet (or moon) in your planet list to copy its coordinates
to the clipboard as a forum-ready `[coordinates]galaxy:system:position[/coordinates]`
tag — no popup, no navigating away.

## Install

Requires [Tampermonkey](https://www.tampermonkey.net/) and OGLight already installed — see the [main README](../../README.md) for setup.

Not yet published to Greasy Fork. To install: open [OGLight-CopyCoords.user.js](OGLight-CopyCoords.user.js), click **Raw**, and Tampermonkey will prompt you to install it.
